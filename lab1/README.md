# Лабораторная работа №1 (Вариант №6)

Везде в задачах подразумевается, что строка - в алфавите латинских строчных букв, переменная - в алфавите заглавных латинских, строка окружена маркерами начала `^` и конца `$`.
В некоторых задачах также встречаются скобки - это единственный вид скобок, круглые `()`.
Образцы в левых и правых частях правил даются исчерпывающе: `^P1$ = ^P2$`, где `P2` не содержит свежих переменных, не входящих в `P1`.
Подразумевается, что получившиеся системы переписывания строк должны быть эквивалентны системам переписывания образцов именно по модулю слов, имеющих представление `^[a-z]*$` (или `^[a-z]|)|($`, если в условии встречаются скобки).

Произвольная правая часть, рефал-стиль
Дано единственное правило переписывания, правая часть которого может быть какой угодно, а в левой нет повторных вхождений переменных. Сопоставление выбирается лексикографически меньшее по длинам значений слева направо.

## Общий алгоритм работы
1. **Оборачивание переменных.** Левая часть правила просматривается слева направо. Каждая переменная заключается в маркеры границ с присвоением ей уникального номера. В конце левой части устанавливается разделитель `-`.
2. **Восстановление правой части.** Правая часть формируется в соответствии с исходным правилом: литералы вставляются непосредственно, а значения переменных копируются из левой части.
3. **Удаление левой части.** После формирования правой части исходная левая часть удаляется. Каретка перемещается по строке, удаляя исходные символы и маркеры переменных, сохраняя построенную правую часть.
4. **Удаление скобок.** В заключительном этапе удаляются оставшиеся маркеры границ переменных, а вспомогательные состояния каретки заменяются обычным перемещением.

## Обозначения 
- `γ` - любой символ 
- `N[...]N` - маркеры границ для переменных (`N` – номер переменной)
- `(>)`, `(<)` - каретка движущаяся вправо и влево соответсвтенно
- `(N>)`, `(<N)` - каретка проходит через переменную с номером N
- `-` – разделение правой и левой частей
- `(<slcN)`, `(<lcN)`,  `(<srcN)`, `(<rcN)`   - каретка для копирования перенной (`N` – номер переменной которую копируем, `s`(start) – копирование только началось, `l`/`r` – двигаемся по левой или правой части отсительно `-`)
- `(Nclf>)`, `(λNclf>)`, `(Ncrf>)`, `(λNcr>)`  - каретка для копирования перенной (`N` – номер переменной которую копируем, `f`(finish) – копирование заканчивается, `l`/`r` – двигаемся по левой или правой части отсительно `-`, `λ` – сивол который мы копируем)
- `&` – метка, которая ставится перед переменной, в которую идёт копирование символов
- `@` – метка перед символом который мы собираемся скопировать
- `(<d)` - каретка удаляет левую часть (относительно `-`)
